# Thryve AI Frontend
The frontend runs react 19, with separate client and admin areas. Use React Router for navigation, Axios for API calls, a CRA proxy for CORS, and
Tailwind CSS for styling. We include all pages/components, routing, and configuration details.

## Project structure
Choose an appropriate project structure

## Client Pages and Components
- Home page: a non-authenticated page about thryve with all details about fitness and importance and images. Color themes should represent health, fitness, workout and strength
- Client Login Page: A simple form that allows for login with google and calls springboot backend. On success navigate to /client/dashboard.
- Client Dashboard: Fetches and populates the user’s details including workouts, progress, goals, health metrics ets from the
backend endpoints. Including creation, editing and deletion

- Admin and dashboard page not available to the public
